# Saim Bashir Portfolio — Forest Light Edition

A static, responsive portfolio built for desktop and mobile browsers.

## Run
Extract the ZIP and open `index.html` directly in a modern browser. No npm or build step is required.

## Design
- Light cream + forest green visual system
- Circular profile portrait with a subtle ring
- Responsive project grid and mobile navigation
- Smooth, lightweight CSS/JavaScript animations
- Project imagery uses `contain` sizing so text and UI are not cropped
- Google Play screenshots request higher-resolution versions and can be opened at full size
- Multi-Agent AI appears as a normal project; its extra information is available only in the project detail drawer

## Notes
Some project covers and Play Store screenshots are loaded from the existing portfolio/GitHub/Google Play URLs, so an internet connection is required for those external images.
